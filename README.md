# Решись Авиа — прогноз спроса / Вариант C

Демо-приложение для задания продвинутого уровня турнира «Решись!»: FastAPI backend + адаптивный HTML/CSS/JavaScript frontend + регистрация/авторизация + интерактивное квантильное распределение спроса + сценарный прогноз.

## Источник данных

Оба набора данных **включены в ZIP** и не подменяются:

- `data/my_forecast.csv` — прогноз пользователя из ML-блока: 155 рейсов, 5 направлений, 9 квантилей.
- `data/routes.csv` — оригинальный файл организаторов: базовые цены, предельные тарифы, себестоимость и чувствительность спроса к цене.

**Восстановленных или оценочных коэффициентов в этой версии нет.** Если `routes.csv` отсутствует или повреждён, сервер сообщает об ошибке вместо молчаливой подстановки приближений.

Исходные CSV не изменялись. Параметры ценовых границ учитываются сервером и отображаются в форме. В результате численного округления колонок файла прогноза заранее сохранённые `X_price_demand` могут отличаться от пересчёта при `X_price` примерно на 1 пассажира; интерактивные расчёты выполняются по исходным числам и полной точности `price_sensitivity`. Это не ошибка построения графика.

Формула:
- желают = max(0, X_base_demand − price_sensitivity × (цена − base_price));
- купят = min(seats, желают).

Для построения графика используются девять квантилей одного прогноза по данным каждого route/date. График показывает квантильную функцию распределения (точки кумулятивного распределения с вероятностями от 10% до 90%), а не выдуманную плотность вероятности. Визуализированы медиана и вместимость.

## Запуск локально

```bash
python -m pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. Создайте личную учётную запись через форму регистрации (предустановленных логинов/паролей нет). Войдите; выбор маршрута, даты и цены выполняет backend API, а график строится на стороне браузера. Проект работает без внешнего CDNs.

## Размещение в интернете

1. Разместите папку проекта в **своём** GitHub-репозитории. Оба CSV уже включены в архив.
2. На Render.com создайте Web Service → подключите репозиторий. Можно использовать `render.yaml` (Blueprint).
3. Команда сборки: `pip install -r requirements.txt`; запуска: `uvicorn main:app --host 0.0.0.0 --port $PORT`.
4. Задайте `APP_SECRET` длинным случайным значением, `HTTPS_COOKIE=1` для HTTPS. Для реальной сохранности пользователей нужна постоянная PostgreSQL/SQLite-диск: на бесплатном эфемерном контейнере аккаунты могут пропадать после перезапуска.
5. Проверьте в браузере регистрацию, вход, все 5 маршрутов, даты и график. Убедитесь, что сайт доступен эксперту до конца оценки. Бесплатный инстанс может просыпаться не сразу.

Нельзя утверждать, что приложение размещено на хостинге, пока не опубликован настоящий URL.

## API

- GET `/api/health`
- GET `/api/options`
- POST `/api/auth/register` — `{username, password}`
- POST `/api/auth/login` — `{username, password}`
- GET `/api/auth/me`
- POST `/api/auth/logout`
- POST `/api/calculate` — `{route:"MOW-AER",date:"2026-06-12",price:9000,quantile:0.5}` (авторизация обязательна)

## Использованные ИИ и инструменты

При подготовке проекта использовался ChatGPT (OpenAI GPT-6) для проектирования системы, генерации кода и написания автотестов. Базовая модель спроса обучалась отдельно в ML-ноутбуке участника; её итоговый CSV используется без изменений. В README **не заявляется**, что автор этого приложения повторно обучал модель или проверил её MAE.

## Для видео (3 минуты на весь кейс)

Покажите, как прогнозы спроса из `my_forecast.csv` используются сервером; создание учётной записи; расчёт на реальных маршруте и дате; изменение цены и графика; затем кратко объясните формулу и сценарии. Обязательно также охватите аналитический и ML-блоки.

### Быстрый запуск на Windows

Распакуйте ZIP и дважды щёлкните `start_windows.bat` (должен быть установлен Python 3.11+). Затем зарегистрируйте учётную запись и проверьте прогноз. Для проверки CSV отдельно используйте `python verify_forecast.py`.
